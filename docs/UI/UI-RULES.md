# 界面与焦点规则

本页只写**规则与机制**。每页有哪些段、每段的列数、方向键具体落到哪，以页面代码里的
`FocusSection` / `FocusPlan` 声明为准；尺寸/字号/颜色以 `Tokens.kt` 为准。不在这里抄第二份。

## 1. 状态语义

同一时刻全页**只有一个白色填充**，就是光标所在项：

| 状态 | 画法 | 用在哪 |
| --- | --- | --- |
| **焦点** | 白底 + 深字 | 当前按确认会执行的控件 |
| **选中** | 白描边 + 白字，不填充 | 当前 tab / 当前筛选 / 当前集 / 当前季 |
| **已看过** | 略亮一档的暗底 | 分集格，仅在没焦点也没选中时显示 |
| 未上线 | 整卡透明度降低 | 搜索/季线里的未上线季 |

封面卡是同一语义的特殊形态：焦点时**卡片背景变白**，但封面图在上层，白色只露在
封面下方的信息条里（看起来就是「封面下层背景变白、文字变深」）。

**不做任何焦点动效**：不缩放、不位移、不加 `translationZ`、不做逐帧动画。
电视性能差异大，动效会引入白框被裁、邻居遮挡、焦点漂移这类难复现的问题。
焦点只改配色。

## 2. 两套方向键机制

| 机制 | 用在哪 | 怎么算 |
| --- | --- | --- |
| **焦点图**（`FocusGraph`） | 目录四页（搜索/收藏/历史/设置） | 段内按列号走；段间按声明顺序上下跨；左右跨段按列/行比例映射 |
| **视觉方向**（`VisualFocus` + `bindVisual`） | 详情两页、播放抽屉 | 按视图真实矩形算；先看 45° 视锥，锥内取最近，锥内没有才退到全方向最近；页面可声明显式出口（`FocusExits`），命中且目标在屏时优先于几何 |

为什么并存：目录页是规则网格，焦点图能精确表达「第 5 列按上落到第 5 列」；
详情页是「返回在左上、继续播放在右上、分集格在下方」的不规则布局，只有真实矩形能表达
「视觉上的右边」。

**边界一律夹住自己**：走到页面边缘时落点是自己，不交给系统几何猜。
空槽保留列位（禁用的翻页键仍占一格），否则「从翻页键往下」会整体错位一张卡。

## 3. 落焦阶梯

进页/页面重建时按固定顺序取第一个**确实有视图**的候选：

```
本次显式目标 → 本页记忆 → 页面声明的阶梯 → 焦点图首项（最后兜底）
```

- 页面阶梯的第一项必须是本页内容；侧栏只能出现在链尾。
- 冷启动时框架会自动把焦点给侧栏第一项；这次落焦**不写进记忆**，否则会压过阶梯。
- 只有**用户主动移动**才写记忆：旧焦点为空、已隐藏、已脱离父容器或已禁用时，框架接管的
  被动落焦一律不记（列表重建瞬间 `isShown` 还没翻转也能拦住）。
- 侧栏 key 不进入跨页保存的光标（但用户主动停在侧栏时，本页内仍可恢复）。

## 4. 信息栏（InfoBand）

- 只在**焦点落定且落在卡片上**时出现；落到输入区、片库、侧栏、管理条时整条收起。
- 「落定」是**一帧防抖**后的结果：焦点从卡 A 路过卡 B 再到卡 C，只按 C 更新，避免中间态闪烁。
- 信息栏内容是「这部剧的事实」：片名 + 集数/已收藏/分类；收藏页换成「观看到…」。
  观看位置在卡片状态条上时不重复写。
- 管理态（历史页 MENU）与信息栏**互斥**：两条底栏会把第二行卡片压掉一半。

## 5. 左侧栏

- 目录四页与详情两页都有左侧栏；焦点可以左右进出。
- 内容往左回侧栏时，落点是**本页当前 tab**（`sideAnchor`），不按竖直位置猜；
  否则只有一行卡时按左会落到侧栏中段，再按确认就换了页。
- 详情两页的侧栏当前项固定亮「收藏」：内容都是收藏语境的延伸。
- 侧栏项只有焦点/当前页两种状态，没有第三个「选中」。

## 6. 页面骨架与滚动

- `PageScaffold` 的树**一次搭好后不再重建**；数据刷新走网格/文本的增量更新。
- 需要空态的页面用 `ContentPane`（滚动内容 + 居中空态，二态互斥）；
  只有「一定有内容」的内页用 `scrollBody()`。
- 光标移出视口时由 `ScrollFocusKeeper` 瞬时滚动到可见处；平滑滚动在老设备上本身就是掉帧源。
- 卡片高度按 `CardFit` 夹取，但**只夹首屏只放得下一行的网格**（如「继续看」）；
  搜索结果不夹，第二行自然探出滚动看全。

## 7. 设计系统

- 页面不写尺寸/颜色字面量，只引用 `Tokens`。新增参数先进令牌，再在页面使用。
- 卡片封面一律 `CENTER_CROP` 满铺；上游封面比例不统一，`FIT_CENTER` 会露白边。
- 图标用 `setTint` 着色（API 21+），不用 `setColorFilter`。
- 焦点态与选中态共用 `stateShape` 的描边规则：**选中才描边，焦点不描边**。
- 低内存档只降单页卡片上限，颜色、字号、尺寸完全一致。

## 8. 新增/修改一页时的检查表

- [ ] 每段都声明在 `FocusPlan` 里，空段整段省略，禁用项用空槽保留列位。
- [ ] 页面给出 `startFocus` 阶梯，第一项是本页内容，侧栏只在链尾。
- [ ] 能程序性落焦的 key 都同时出现在 `views` 映射里（只声明段不给 View = 永远选不中）。
- [ ] 详情/抽屉这类不规则布局用 `visual = true`，并确认布局完成后再绑定。
- [ ] 信息栏挂在焦点落定回调上，不在「卡片获得焦点」上。
- [ ] 刷新列表时优先复用视图；顺序变化要保住焦点与滚动位置。
- [ ] 视觉方向里"几何最近项会跑出页面"的路径用 `FocusExits` 声明固定落点。
- [ ] 用遥控器走一圈：进页、四个方向、确认、返回、再进页。
